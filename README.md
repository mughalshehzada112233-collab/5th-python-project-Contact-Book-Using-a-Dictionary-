# 5th-python-project-Contact-Book-Using-a-Dictionary-
Create a simple Contact Book in Jupyter Notebook. The program should keep running until the user
chooses Exit.
- Add a contact with name, phone number, and email address.
- Search for a contact by entering the contact name.
- Display the saved phone number and email when the contact is found.
- Show a clear message when the contact is not found.
- Close the program when the user selects Exit.
